# 퍼스트 폐차 (First Pecha)

차량번호로 1분 만에 폐차 예상견적을 받는 랜딩페이지 + 관리자 시스템.
정부 관허 폐차장 **대성폐차산업(주)** (양주) 운영. 헤이딜러 폐차 UX를 벤치마킹.

## 구성
- `index.html` — 고객용 단일 파일 랜딩페이지 (모바일 최적화)
- `admin.html` — 관리자 페이지 (문의 관리·견적 계산기·문자 발송)
- `privacy.html` — 개인정보처리방침
- `api/` — Vercel 서버리스 함수 (아래 참고)
- `supabase_pecha.sql` — `pecha_estimates` 테이블 + RLS 보안 설정
- `hero.jpg`, `og.jpg` — 메인/공유 이미지
- `robots.txt`, `sitemap.xml` — 검색엔진 노출용

## 기술 스택
- **프론트**: 정적 HTML/CSS/JS (프레임워크 없음), Wanted Sans + Pretendard
- **데이터**: Supabase (`pecha_estimates`, RLS — 익명 insert만 / 로그인 select·update)
- **호스팅**: Vercel (서버리스 함수 + 클린 URL)
- **간편인증 견적**: CODEF 비회원 간편인증 → 자동차등록원부(갑) 조회
- **문자 발송**: 솔라피(Solapi) SMS API

## 주요 기능
### 고객 (index.html)
- **무료견적**: 차량번호 + 연락처만 입력 → 접수
- **차급 즉시견적**: 주민번호·인증 없이 차급/연식/연료 선택 → 예상견적 즉시 표시
- **간편인증 정확견적**: 휴대폰 간편인증(주민번호)으로 차량정보 자동조회 → 정밀 견적
- 접수 시 고객에게 **자동 확인 문자** 발송 (차량번호 개인화, 중복 발송 방지)

### 관리자 (admin.html)
- 문의 목록·상태 관리, 유입경로(무료견적/간편인증) 구분, CSV 내보내기
- **견적 계산기**: 공차중량 × 고철시세 + 촉매(연식·연료) → 예상 매입가 자동 산출
- **문자 발송 버튼**: 확정견적을 고객에게 솔라피로 직접 발송 (관리자 로그인 검증)
- 자동문자 발송 여부 표시

## API 엔드포인트 (`api/`)
| 파일 | 역할 |
|------|------|
| `vehicle.js` | CODEF 간편인증 → 자동차등록원부 조회 |
| `lead.js` | 리드 저장/중복 병합 (무료견적↔간편인증 = 1행), `service_role` 사용 |
| `notify.js` | 접수 시 고객 자동 문자 (솔라피), `sms_sent`로 중복 방지 |
| `send-quote.js` | 관리자 수동 문자 발송 (솔라피), 관리자 로그인 검증 |
| `ping.js` | 상태 확인용 |

## 환경변수 (Vercel)
| 변수 | 용도 |
|------|------|
| `SUPABASE_SERVICE_KEY` | 서버에서만 사용하는 service_role 키 (중복 병합·발송표시) |
| `SOLAPI_API_KEY` / `SOLAPI_API_SECRET` | 솔라피 인증 |
| `SOLAPI_SENDER` | 등록된 발신번호 |
| `CODEF_*` | CODEF 인증 관련 키 |

> 값은 **Vercel 환경변수에만** 저장. 코드·깃허브에는 절대 넣지 않음.

## 배포
1. `firstpecha` 폴더 전체를 Vercel 프로젝트 Overview에 드래그
2. `api/` 폴더가 포함됐는지 확인
3. 환경변수는 다음 배포부터 적용됨

## 보안 원칙
- 프론트에는 **publishable(anon) 키만** 사용 → RLS로 보호
- service_role·솔라피·CODEF 비밀키는 **Vercel 환경변수** 전용
- 주민번호는 **간편인증 조회 시에만** 쓰고 저장하지 않음
- 개인정보(연락처·차량번호)는 HTTPS + 수집 동의 후 저장
